# API Documentation

## Edge Functions

### match-score
Calculates match score between candidate and job.

**Endpoint**: `POST /functions/v1/match-score`

### parse-resume
Parses resume and extracts structured data.

**Endpoint**: `POST /functions/v1/parse-resume`

### send-email
Sends email notifications.

**Endpoint**: `POST /functions/v1/send-email`

### send-whatsapp
Sends WhatsApp messages.

**Endpoint**: `POST /functions/v1/send-whatsapp`
