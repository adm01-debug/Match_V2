# Guia do Usuário

## Primeiros Passos

### Login
1. Acesse a aplicação
2. Entre com email e senha
3. Complete a verificação se necessário

### Dashboard
O dashboard mostra:
- KPIs principais
- Vagas urgentes
- Próximas entrevistas
- Ações pendentes

## Funcionalidades

### Gerenciar Vagas
1. Clique em "Vagas" no menu
2. Use "Nova Vaga" para criar
3. Preencha os detalhes
4. Publique a vaga

### Gerenciar Candidatos
1. Clique em "Candidatos"
2. Visualize a lista ou use filtros
3. Clique em um candidato para detalhes
4. Avalie e mova no pipeline

### Pipeline
1. Acesse "Pipeline"
2. Arraste candidatos entre etapas
3. Clique para ver detalhes
4. Agende entrevistas

### Agenda
1. Acesse "Agenda"
2. Veja entrevistas agendadas
3. Crie novos agendamentos
4. Integre com Google Calendar
