# Glossário

## Termos de Negócio

| Termo | Definição |
|-------|-----------|
| **ATS** | Applicant Tracking System - Sistema de rastreamento de candidatos |
| **Vaga** | Posição aberta para contratação |
| **Candidato** | Pessoa que se candidata a uma vaga |
| **Pipeline** | Fluxo de etapas do processo seletivo |
| **Match Score** | Pontuação de compatibilidade candidato-vaga |
| **Processo Seletivo** | Conjunto de etapas para preencher uma vaga |

## Termos Técnicos

| Termo | Definição |
|-------|-----------|
| **RLS** | Row Level Security - Segurança a nível de linha |
| **Edge Function** | Função serverless executada na edge |
| **Realtime** | Comunicação bidirecional em tempo real |
| **KPI** | Key Performance Indicator - Indicador de performance |

## Entidades do Sistema

| Entidade | Descrição |
|----------|-----------|
| `candidatos` | Tabela de candidatos |
| `vagas` | Tabela de vagas |
| `candidaturas` | Relação candidato-vaga |
| `entrevistas` | Agendamentos de entrevistas |
| `avaliacoes` | Avaliações de candidatos |
