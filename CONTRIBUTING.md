# Contribuindo para o Match ATS

Obrigado por considerar contribuir para o Match ATS!

## Como Começar

1. Fork o repositório
2. Clone seu fork: `git clone https://github.com/seu-usuario/match.git`
3. Instale dependências: `npm install`
4. Crie uma branch: `git checkout -b feature/minha-feature`

## Padrões de Código

- Use TypeScript
- Siga o ESLint configurado
- Use componentes funcionais com hooks
- Mantenha componentes pequenos e focados

## Commits

Usamos Conventional Commits:
- `feat:` nova funcionalidade
- `fix:` correção de bug
- `docs:` documentação
- `style:` formatação
- `refactor:` refatoração
- `test:` testes
- `chore:` manutenção

## Pull Requests

1. Atualize sua branch com main
2. Rode os testes: `npm run test`
3. Rode o lint: `npm run lint`
4. Descreva suas mudanças claramente

## Reportando Bugs

Use as Issues do GitHub com:
- Descrição clara do problema
- Passos para reproduzir
- Comportamento esperado vs atual
- Screenshots se aplicável
